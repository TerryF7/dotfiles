# Preferences

- Write configuration comments, documentation, and commit messages in English.
- Use short, single-line comment headings without decorative separators; keep necessary explanations brief and preserve tool directives and default tutorial comments.
- Keep README.md limited to installation steps.
- Prefer native chezmoi features and official tool workflows over custom scripts.
- Use Homebrew for standalone software and manage dependencies in Brewfile.
- Edit chezmoi source files rather than deployed files.
